# 📊 Zepto Sales Dashboard

## 📌 Description

An end-to-end sales performance and business intelligence dashboard built on Excel to analyze Zepto's retail operations. The dashboard focuses on revenue growth, customer satisfaction, and inventory performance through structured KPIs and interactive visualizations. It enables data-driven decision-making by identifying high-performing outlets, profitable product categories, and customer-centric trends — helping optimize sales strategy, inventory planning, and retail expansion.

## 🛠️ Tech Stack

The dashboard was built using the following tools and technologies:

- **Excel** – Main platform used for data analysis, report and dashboard building
- **Power Query** – ETL, data transformation, and cleaning layer for reshaping and preparing the data
- **Pivot Tables** – To analyse the data in a tabular form with advanced filters
- **Pivot Charts** – To visualize the data of Pivot Tables with advanced visual charts
- **Slicers** – Used to filter out data visualizations
- **Data Visualizations** – To visualize Zepto sales KPIs and other related metrics
- **File Formats** – `.xlsx` for development and `.png` for dashboard previews

## 🗄️ Dataset

An open-source dataset simulating Zepto's sales records, provided in Excel format. The dataset consists of 1 fact table structured as follows:

**Data Table**
- Columns: Item Fat Content, Sr No, Item Identifier, Item Type, Outlet Establishment Year, Outlet Identifier, Outlet Location Type, Outlet Size, Outlet Type, Item Visibility, Item Weight, Total Sales, Rating

## 💡 Features / Highlights

### 📈 Key Business KPIs Tracked

- **Total Sales** – Overall revenue generated
- **Average Sales** – Revenue per transaction
- **Number of Items Sold** – Product distribution
- **Average Rating** – Customer satisfaction indicator

### 📉 Analytical Views Designed (Visualizations)

- **Total Sales by Fat Content (Donut Chart)** – Impact of product nutrition on revenue
- **Sales by Item Type (Bar Chart)** – Category-wise performance
- **Fat Content vs Outlet Sales by Store Type (Clustered Bar Chart)** – Sales across different types of store outlets categorized by fat content
- **Sales by Outlet Establishment (Line Chart)** – Performance by store's establishment timeline
- **Sales by Outlet Size (Donut/Pie Chart)** – Store size vs revenue correlation
- **Sales by Outlet Location (Funnel Map)** – Geographic sales distribution
- **All KPIs by Outlet Type (Matrix Card)** – Holistic outlet-level comparison
